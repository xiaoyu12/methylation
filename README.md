# README
This repository contains the code and processed data file for the paper "Integration of DNA Methylation and Gene Expression Analysis in Gephyrocapsa huxleyi Provides Insight into Genes Related to Calcification". It has the following folders.

### Data
- The BED files of differentially methylated cytosines(DMCs), and differentially methylated regions (DMRs).
- The list and annotations of differentially expressed genes (DEGs), and differentially methylated genes (DMGs) and promoters (DMPs).

### meth_analy
- R scripts to analyze and plot the methylation data

### enrichment analysis
- Rscripts to analyze and plot the encrichment analysis results.

### stat_analy
- Rescripts to analyze the statitiscal correlation between methylation changes and gene expression variations using RStan models.
