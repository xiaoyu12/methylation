# Data files for the paper "Integration of DNA Methylation and Gene Expression Analysis in Gephyrocapsa huxleyi Provides Insight into Genes Related to Calcification".

- DEGs.xlsx: Differentially expressed genes between the strain CCMP1516 and M217.
- DMCs.bed: BED file of differentially methylated sites (DMCs).
- DMRs.bed: BED file of differentially methylated regions (DMRS).
- DMGs.xlsx: Differentially methylated genes (DMGs) are genes that overlap with DMRs
- DMPs.xlsx: Differentially methylated promoters (DMPs) are defined as 2,000 bp segments upstream of TSS overlapping DMRs.
